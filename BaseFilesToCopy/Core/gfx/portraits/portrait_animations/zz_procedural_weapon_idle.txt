# Generated-mod override of vanilla's 'idle' portrait animation.
#
# This file deliberately re-declares the WHOLE 'idle' key. Portrait animations are a
# last-wins database keyed on the top-level name, so this replaces vanilla's idle and
# leaves every other key (chancellor, steward, ...) untouched. It must NOT be named
# animations.txt - a same-path file replaces the vanilla file outright and would drop
# all the other animations.
#
# Body copied verbatim from vanilla animations.txt, plus the pmg_hold_*_idle items marked
# below, minus vanilla's references to its own historical characters (character_murchad,
# character_robert, character_yahya, the easteregg_henry_* ids, and the character:7757 /
# character:41702 tweaks on camp_purpose_scholars, AI_rational and AI_zealous): those
# characters do not exist on a generated map. Re-copy from vanilla after a patch that touches it.
#
# Re-copied from 1.20.0.2 on 2026-09-30 (animations.txt lines 14-2222). 1.20 is what broke the
# old copy: its three holding_hu_* items asked `government_allows = administrative`, a
# government rule 1.20 deleted ("Not a valid government rule"), and vanilla now asks
# `government_has_mechanic = administrative` and reads the gender doctrine off the rite.
# character_henry is kept this time with only its ids removed, because 1.20 gave it a second
# clause (Christian military-order rulers at war) that is about no particular character.
