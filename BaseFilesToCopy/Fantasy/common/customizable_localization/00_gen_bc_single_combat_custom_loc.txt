# Orcish wording for vanilla's single-combat moves, during a Blood Challenge only.
#
# Vanilla's round event (events/single_combat_events.txt, single_combat.0001) names each move with a
# fixed loc key. localization/replace/english/zz_gen_bc_single_combat_l_english.yml points those 69
# keys (move names and their tooltips) at the entries below; a fighter carrying gen_bc_in_challenge
# (set for the whole Blood Challenge chain) reads gen_bc_sc_orc.*, everyone else reads
# gen_bc_sc_vanilla.* — vanilla's own text, copied verbatim (gen_bc_single_combat_l_english.yml).
# Mechanics are untouched: only the words change.
#
# UPKEEP: the vanilla copies go stale if a CK3 patch rewrites one of these lines. After an update, diff
# the copies against game/localization/english/single_combat_events_l_english.yml.
